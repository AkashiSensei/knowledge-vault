# SOSP 2026 论文列表

截至 2026-09-20，SOSP 2026 尚未召开（会议日期为 2026-09-29 至 10-02），官方已公布 62 篇录用论文，但正式 proceedings 尚未发布。以下列表以官方录用页和日程为全集基准：31 篇已有可解释核心工作的公开论文摘要或预印本，Smaran 仅有 artifact 说明，其余 30 篇只公开题名、作者与 session，相关条目会明确标注证据边界，不把题名推测当作已公开机制。当前可合法获得的 30 份 PDF 已保存到 `reference/SOSP/2026/`，正式版本发布后应再统一复核与补全。

- [A Few GPUs, A Whole Lotta Scale: Faithful LLM Training Emulation with CrystalLLM](https://doi.org/10.48550/arXiv.2605.15617)
  - Alibaba Group、Shanghai Jiao Tong University and Alibaba Group、Harvard University、Shanghai Jiao Tong University、Zhejiang University；Shaoke Xi、ChonLam Lao、Boyi Jia、Jiaqi Gao、Zhipeng Zhang、Jiamin Cao 等
  - PrismLLM 面向千卡级 LLM 训练框架的复现、调试和性能调优：它先从目标规模的完整执行图中切出需要观察的 rank 及其计算、通信依赖，只让少量真实 GPU 执行这些 rank，其余 rank 作为虚拟参与者回放。它用不足目标规模 1% 的 GPU 模拟最多 8192 卡训练，迭代时间平均误差 0.58%，峰值显存误差低于 0.01%。
  - 相较依赖易失真的性能模拟器或不能复现规模效应的缩小实验，核心创新是以执行图切片和“真实 rank + 虚拟 rank”混合回放保留目标集群的依赖与资源行为。
  - LLM 训练系统、超大规模集群仿真、执行图切片、混合仿真、故障复现与调优

- [AgileLog: A Forkable Shared Log for Agents on Data Streams](https://arxiv.org/abs/2604.14590)
  - University of Illinois Urbana-Champaign；Shreesha G. Bhat、Tony Hong、Michael A Noguera、Aishwarya Ganesan、Ramnatthan Alagappan
  - AgileLog/Bolt 面向在流数据上读取、推理并可能写回的 AI Agent，把流系统底层 shared log 扩展为可 fork 的日志：每个 Agent 可在隔离分支上试探性消费和修改流状态，再按策略处理结果；实现重点是让 fork 足够廉价，并同时隔离错误写入和 Agent 长时推理造成的性能干扰。
  - 相较只为确定性流处理程序提供单一线性日志，核心创新是把可分叉日志提升为 Agent 的基础存储原语，使 speculative agent action 同时具备逻辑隔离和性能隔离。
  - Agent Infra、流处理、Forkable Shared Log、试探性写入、逻辑与性能隔离

- [Ahead-of-time Analysis of Shell Program Effects](https://www.semanticscholar.org/paper/e86a1469dac3ad6ee4bc5b004de198ff46dc72b9)
  - Brown University、Stevens Institute of Technology、University of California, Los Angeles；Lukas Lazarek、Evangelos Lamprou、George Kapetanakis、Anirudh Narsipur、Eric Zhao、Zhiwen Zheng 等
  - SaSh 在 shell 脚本真正执行前预测可能造成的数据删除、错误路径等副作用。它用乐观符号执行联合建模 shell 展开语义、外部命令对文件系统的影响，并用风险导向搜索优先探索高危片段；在 61 个已知问题上除 1 个外全部检出且无误报，并在 44 个项目中报告 70 个新 bug。
  - 相较只分析 shell 自身语法或穷举路径，核心创新是把外部命令的文件系统 effect 纳入符号状态，并用面向破坏性后果的搜索控制路径爆炸。
  - Shell 静态分析、符号执行、文件系统 Effect、风险导向搜索、系统脚本安全

- [Anchor: Mitigating GPU Shallow Disruptions with Decoupled Memory](https://sigops.org/s/conferences/sosp/2026/accepted.html)
  - Tsinghua University、Shanghai Jiao Tong University；Haoyi Ma、Shiwei Gao、Youmin Chen、Junrong Huang、Youyou Lu、Jiwu Shu
  - Anchor 面向训练和推理过程中 GPU 出现“shallow disruption”但作业状态仍可恢复的场景，目标是把计算恢复与大体量 GPU 内存状态解耦，避免每次轻微中断都按整卡/整作业失败处理。公开 artifact 表明系统同时集成 DeepSpeed 与 vLLM，并评测恢复分解、端到端训练吞吐、推理延迟和显存开销；论文算法细节尚未公开。
  - 现有公开材料能确认的差异化是以 decoupled memory 保留/复用状态来处理非致命 GPU 中断，并统一覆盖训练与在线推理；故障检测、状态迁移和恢复协议的具体创新仍需等论文公开。
  - AI 基础设施可靠性、GPU 浅层故障、训练与推理恢复、显存状态解耦、会前信息待补

- [Ave: Guiding Agentic GPU Optimization Using Data-Flow Invariants](https://arxiv.org/abs/2604.18616)
  - HKUST、University of Chinese Academy of Sciences, China、University of California, Riverside、University of Science and Technology of China、Tsinghua University；Haohui Mai、Xiaoyan Guo、Xiangyun Ding、Daifeng Li、Qiuchu Yu、Chenzhun Guo 等
  - Ave 是优化 GPU kernel 的 Agent for Systems：ICRL planner 从优化知识中提出 shared-memory staging、流水和指令调度等方案，lowering agent 将方案落到 tile-based DSL；编译器传播 data-flow tag，并用 SMT 检查每次改写必须保持的全局不变量，违规时把具体反例反馈给 Agent。它在 MI300X 的 GEMM、FlashAttention 和 MoE 上达到手工库 89%–99% 的有效吞吐。
  - 相较只用单测通过/失败和端到端 profile 给代码 Agent 稀疏反馈，核心创新是把可证明的数据流不变量变成 Agent 优化过程的细粒度 guardrail 与反例反馈通道。
  - Agent for Systems、GPU Kernel 自动优化、Data-flow Invariant、SMT 验证、Agent-Compiler 协同

- [Batched in Back: Characterizing and Optimizing Offline LLM Inference in Production with ACDC](https://sigops.org/s/conferences/sosp/2026/accepted.html)
  - Shanghai Jiao Tong University and Alibaba Group、Alibaba Group、Shanghai Jiao Tong University；Leping Yang、Xue Li、Kun Qian、Erci Xu、Mingzhen Han、Haoran Zhu 等
  - ACDC 研究生产环境中的离线 LLM 推理，而非逐请求到达、受交互延迟约束的在线服务。公开的 Alibaba Cloud Model Studio trace 以完整 batch task 为调度单元，记录各请求输入/输出长度、prefix block hash、图像标识和执行时长，用于刻画批任务内部的前缀复用与长度异质性；ACDC 如何据此组批、放置和分配资源尚未公开。
  - 可确认的差异化是把 offline batch inference 作为独立工作负载研究，并由真实批任务的请求结构而非在线到达率驱动优化；具体调度机制及量化收益需等论文公开。
  - 离线 LLM 推理、生产负载刻画、Batch Task、Prefix Cache 复用、会前信息待补

- [Beyond Utilization: Energy-Conscious GPU Sharing for Inference Serving](https://sigops.org/s/conferences/sosp/2026/accepted.html)
  - The University of Texas at Austin；Prasoon Sinha、Dimitrios Liakopoulos、Nathan Lemma、Neeraja J. Yadwadkar
  - 该工作研究多租户推理服务中的 GPU sharing，不只追求利用率或请求吞吐，而把能耗纳入共享决策。官方目前仅公开题名、作者和“Model Serving at Scale”归类，尚未说明控制粒度是请求、模型实例还是 GPU slice，也未公开能耗模型、SLO 约束与调度算法。
  - 可确认的差异化目标是纠正“高利用率等于高能效”的假设，联合考虑共享和推理能耗；相较既有方法的具体机制创新目前不能可靠判断。
  - 推理服务、GPU Sharing、能耗感知调度、SLO、会前信息待补

- [Big Bird: Resilient Privacy Budgeting Across Untrusted Web Domains](https://arxiv.org/abs/2506.05290)
  - Columbia University、Meta Inc.、University of British Columbia、Mozilla；Pierre Tholoniat、Alison Caulfield、Giorgio Cavicchioli、Mark Chen、Benjamin Case、Asaf Cidon 等
  - Big Bird 面向跨多个不可信 Web 域的广告归因查询，在设备与 epoch 维度统一管理 individual-DP 隐私预算，而不是让每个广告主域各自获得一份预算。系统把可消耗额度与真实 impression/conversion 绑定，防止攻击者创建大量域名或查询耗尽/放大预算，并在 Firefox Attribution 场景评估。
  - 相较 per-domain 独立记账，核心创新是把隐私边界提升到跨域的真实用户事件，并设计可抵抗 Sybil 域和预算耗尽攻击的配额机制。
  - Web 隐私、差分隐私预算、广告归因、跨域记账、Sybil 防御

- [Borges: A Low-Latency Distributed Shared Log on a CXL Memory/SSD Hybrid](https://sigops.org/s/conferences/sosp/2026/accepted.html)
  - The University of Texas at Austin、Anthropic PBC、UIUC；Haowei Chen、Yiming Xiang、Zhipeng Jia、Yan Sun、Nam Sung Kim、Emmett Witchel
  - Borges 研究 CXL memory 与 SSD 混合介质上的低延迟 distributed shared log，目标是在多主机共享内存速度、容量/持久化成本和日志顺序语义之间取舍。官方尚未公开它如何在两种介质间放置记录、提交与恢复，也没有延迟/吞吐结果。
  - 可确认的差异化目标是把 CXL 共享内存与 SSD 组成一个分布式日志数据路径，而不是单独用网络复制内存日志或纯 SSD 日志；具体协议创新仍待论文。
  - 分布式共享日志、CXL Memory、SSD 分层、持久化、会前信息待补

- [Cerium: A Multi-GPU Framework for Terabyte-Scale Encrypted Inference](https://arxiv.org/pdf/2512.11269)
  - Carnegie Mellon University、University of Texas at Austin、NVIDIA；Siddharth Jayashankar、Joshua Kim、Michael B. Sullivan、Wenting Zheng、Dimitrios Skarlatos
  - Cerium 让从 CNN、BERT 到 Llama3-8B 的模型能在密文上做 FHE 推理。DSL、编译器和 runtime 联合生成 GPU kernel，以稀疏多项式表示和紧凑 layout 管理 TB 级中间状态，再按通信代价跨 GPU 并行；Llama3-8B 密文推理约 134 秒，bootstrapping 为 7.5 ms。
  - 相较只优化可装入单卡的小模型或依赖专用 FHE ASIC，核心创新是把 kernel 生成、TB 级内存管理和通信感知多 GPU 并行放进统一软件栈，在通用 GPU 上扩展到 LLM。
  - 隐私计算、全同态加密推理、多 GPU Runtime、编译优化、TB 级内存管理

- [Cohort: Decentralized PIR](https://sigops.org/s/conferences/sosp/2026/accepted.html)
  - The Hebrew University of Jerusalem；Jonathan Weiss、Yossi Gilad
  - Cohort 研究 decentralized private information retrieval，使客户端在不暴露所查询条目的前提下从分散参与方取数，并避免依赖单一中心服务。官方目前没有公开参与方信任模型、查询协议、容错边界和通信复杂度。
  - 可确认的差异化目标是把 PIR 从集中式服务器假设推进到去中心化部署；具体密码学与系统优化相较既有 PIR 的创新尚不能可靠判断。
  - Private Information Retrieval、去中心化隐私服务、查询隐私、分布式协议、会前信息待补

- [Computation is Fast, Use Threadlet!](https://sigops.org/s/conferences/sosp/2026/accepted.html)
  - Peking University and Beijing Tongming Lake Information Technology Application Innovation Center (TLAIC)、Peking University、EPFL、Michigan Technological University、UCLA；Yiming Yao、Xiaohe Qin、Yi Fan、Yuanlong Li、Kang Hu、Liujia Li 等
  - Threadlet 针对“计算已经很快、线程运行时开销反而主导”的 OS/虚拟化场景，尝试以更轻量的执行单元或调度接口降低线程创建、切换和协调成本。官方尚未公开 Threadlet 的状态边界、内核接口、隔离语义以及适用工作负载。
  - 从题名可确认的核心切入点是重新缩小传统 thread abstraction，而不是继续只优化计算 kernel；具体机制和相对收益仍待论文公开。
  - 轻量执行单元、线程运行时、OS 调度、虚拟化、会前信息待补

- [CryptDough: A unified analytics engine for secure multiparty computation](https://arxiv.org/abs/2608.17529)
  - Boston University；Muhammad Faisal、Alessandra Lanz、Sam Buxbaum、Adam Godel、Vasiliki Kalavri、Mayank Varia 等
  - CryptDough 让互不信任的参与方在私有输入上联合执行关系查询、时序分析和 ML inference。它把高层 pipeline 逐层 lowering 到同一 MPC runtime，并以 virtual vector 让开发者写单线程逻辑、由执行引擎负责通信、并行和内存；在既有系统支持的任务上通常快 2 倍以上。
  - 相较一个 MPC 系统绑定一种 threat model 或一种工作负载，核心创新是用分层 IR 与 virtual vector 在同一 runtime 中统一跨领域分析和多种安全假设。
  - 安全多方计算、统一分析引擎、分层 Lowering、Virtual Vector、隐私 ML 推理

- [DDB: Source-Level Interactive Debugging for Distributed Applications](https://arxiv.org/abs/2607.06107)
  - University of Southern California；Yibo Yan、Junzhou He、Seo Jin Park
  - DDB 为跨 RPC 的分布式应用提供类似单进程 debugger 的交互体验：RPC 携带因果元数据以重建 distributed backtrace，控制面把 breakpoint 意图传播到动态进程集合，Pause-Erased Time 则虚拟化各进程时钟，避免人为暂停触发 timeout cascade。它在最多 122 个进程上保持 1%–5% 吞吐开销。
  - 相较依赖 log-and-redeploy 或只能停单进程，核心创新是把跨进程调用栈、动态 breakpoint 生命周期和暂停期间的逻辑时间一起纳入 debugger 语义。
  - 分布式调试、Distributed Backtrace、断点协调、虚拟时间、RPC 因果链

- [DiFlow: A System for Micro-Serving Text-to-Image Diffusion Workflows](https://arxiv.org/pdf/2604.08123)
  - Hong Kong University of Science and Technology & Alibaba Group & Shanghai Jiao Tong University、Hong Kong University of Science and Technology、Alibaba Group；Lingyun Yang、Suyi Li、Tianyu Feng、Xiaoxiao Jiang、Zhipeng Di、Weiyi Lu 等
  - DiFlow/LegoDiffusion 把 text-to-image diffusion workflow 从一个整体服务拆成多个 model-execution microservice，使 text encoder、base diffusion model 等节点能独立扩缩、共享和选择并行方式。这样系统可按 workflow 内部数据流调度资源，而不是给整条流水线固定配置；最高承受 3 倍请求率和 8 倍突发流量。
  - 相较把多模型生成流程当作 opaque monolith，核心创新是把每个模型执行节点变成独立调度对象，从而在集群层联合实现模型共享、per-model scaling 与 adaptive parallelism。
  - 文生图推理、Diffusion Workflow、Micro-serving、模型共享、细粒度弹性

- [DISCO*: DIstributed and SCalable Oblivious Joins and Oblivious Primitives](https://doi.org/10.5281/zenodo.22214075)
  - University of California, Santa Cruz、Hong Kong University of Science and Technology、Hong Kong University of Science & Technology、ATHENA Research Center & Technical University of Crete；Apostolos Mavrogiannakis、Xian Wang、Ioannis Demertzis、Dimitrios Papadopoulos、Minos Garofalakis
  - DISCO 在多台 TEE 上执行完全 oblivious 的数据库 join 与基础算子，既隐藏数据，也避免访问模式经侧信道泄露。系统以一组分布式 oblivious framework 并行计算并减少跨服务器通信，首次把此类计算扩到 TB 级；非外键 join 相较 Jodes/SODA 最多快 88/180 倍。
  - 相较单机 enclave 或难以扩展的 oblivious protocol，核心创新是把 TEE 与可并行的 oblivious primitive 组合成分布式数据库执行层，并专门压缩服务器间通信。
  - TEE、Oblivious Database、分布式 Join、访问模式隐私、TB 级安全分析

- [Disk-Based LSMs: An Unexpectedly Good Index for Partly Coherent CXL Memory](https://www.semanticscholar.org/paper/d2d3316cf7e761ec16e3dc4001d4ae429db61ac2)
  - University of Illinois Urbana-Champaign、NVIDIA；Kiran Hombal、Jiyu Hu、Marcos K. Aguilera、Ramnatthan Alagappan、Aishwarya Ganesan
  - 该工作为只有一小块 cache-coherent 区域的 CXL shared memory 设计内存 range index。传统 ART/B-tree 需要大面积原地更新，软件一致性代价很高；系统改用原本面向磁盘的 LSM，把可变表面压小，并只允许上层原地更新，峰值吞吐较移植的内存索引最高提升 9.4 倍。
  - 相较直接把内存树移植到部分一致 CXL，核心创新是把“可原地修改的表面大小”识别为首要指标，并反常规地用 LSM 的追加/合并结构适配共享内存。
  - CXL 共享内存、Range Index、LSM Tree、部分缓存一致性、软件一致性

- [Don't Let AI Agents YOLO Your Files: Information and Control in Agent-Native Filesystems](https://arxiv.org/abs/2604.13536)
  - Wanxiang、University of Wisconsin-Madison、Microsoft Research、Iowa State University、University of Wisconsin–Madison；Shawn  Zhong、Junxuan Liao、Jing Liu、Mai Zheng、Andrea Arpaci-Dusseau、Remzi Arpaci-Dusseau
  - YoloFS 是 Agent-native filesystem：Agent 的所有文件修改先 staging，文件系统为中间步骤保存 snapshot 供 Agent 自我纠错，并用 progressive permission 让用户在运行中调整访问规则；最终由用户 review/commit。它从 290 个真实事故归纳 introspect、undo、gate 三类原语，在 11 个隐藏副作用任务中让 Agent 自纠 8 个且保留全部变更供审查。
  - 相较只靠 Agent prompt 或一次性 sandbox 权限，核心创新是把副作用可见性、回滚与访问门控下沉为文件系统原语，在维持自治的同时保留可恢复的人类控制点。
  - Agent Infra、Agent-native Filesystem、事务化文件修改、渐进权限、可逆副作用

- [Efficient GPU Multitasking with Morphable Kernels](https://sigops.org/s/conferences/sosp/2026/accepted.html)
  - Tsinghua University；Tingxu Ren、Ruwen Fan、Hao Guo、Minhui Xie、Shiwei Gao、Jiwu Shu 等
  - 该工作研究多任务共享 GPU 时如何让 kernel 具有可变形态，使运行中的 kernel 能适应资源被其他任务占用或释放，而不必固定 launch configuration。官方尚未公开“morphable”改变的是 block、SM 配额还是 kernel variant，也未公开抢占与公平性机制。
  - 可确认的差异化目标是让 kernel 自身配合 GPU multitasking 动态改变资源形态，而不只在 kernel 外部做时分调度；具体实现创新仍待论文。
  - GPU 多任务、Morphable Kernel、资源共享、动态并发、会前信息待补

- [GAZE: Rearchitecting Log-Structured Filesystem for Garbage Collection on Zoned Namespace Flash Storage](https://sigops.org/s/conferences/sosp/2026/accepted.html)
  - KAIST、Korea Advanced Institute of Science and Technology；Juwon Kim、Hwanseok Yoo、Seung Won Yoo、Youjip Won
  - GAZE 面向 ZNS SSD 上的 log-structured filesystem，重新设计 garbage collection，以适配 zone 顺序写、整区回收和有效数据搬迁的约束。官方尚未公开它如何选择 victim zone、协调前台写入与 GC，以及使用哪些设备状态预测回收代价。
  - 可确认的差异化是从文件系统结构层重做面向 ZNS 的 GC，而不是把传统 LFS 清理器直接放在分区设备上；核心算法与结果待论文。
  - ZNS SSD、Log-structured Filesystem、垃圾回收、写放大、会前信息待补

- [I3DP: Neuro-symbolic Inductive Invariant Inference for Distributed Protocols](https://doi.org/10.5281/zenodo.22025609)
  - Nanjing University、Hunan University、Birkbeck, University of London；Weining Cao、Guangyuan Wu、Yuan Yao、Hengfeng Wei、Taolue Chen、Xiaoxing Ma
