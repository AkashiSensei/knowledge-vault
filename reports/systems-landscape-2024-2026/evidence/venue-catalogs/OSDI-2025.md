# OSDI 2025 论文列表

官方 Technical Sessions 共收录 53 篇论文。以下标题均链接至对应的 USENIX 官方论文页；每篇依次列出机构与主要作者、核心工作、相较既有方法的核心创新，以及能直接识别研究对象和技术路径的细粒度方向。

- [Basilisk: Using Provenance Invariants to Automate Proofs of Undecidable Protocols](https://www.usenix.org/conference/osdi25/presentation/zhang-tony)
  - University of Michigan、University of Wisconsin–Madison、Carnegie Mellon University；Tony Nuda Zhang、Keshav Singh、Tej Chajed 等
  - Basilisk 为不限制在可判定逻辑片段内的分布式协议自动寻找 inductive invariant。Provenance Invariant 把某主机局部变量追溯到令其取当前值的 protocol step，再跨 provenance 链推出主机间关系；Atomic Sharding 静态分析每个步骤，自动构造这类不变量并证明归纳性。16 个协议都无需再人工发明新不变量即可完成 safety proof。
  - 相较自动工具要求受限表达、通用协议又需人工猜复杂跨机 invariant，核心创新是把“值从哪一步产生”作为可机械恢复的证明结构，从局部 provenance 自动导出全局关系。
  - 分布式协议验证、Provenance Invariant、Atomic Sharding、自动归纳不变量

- [Deriving Semantic Checkers from Tests to Detect Silent Failures in Production Distributed Systems](https://www.usenix.org/conference/osdi25/presentation/lou)
  - University of Virginia、Bandung Institute of Technology、Penn State、Johns Hopkins、University of Michigan、University of Toronto、Microsoft Research；Chang Lou、Dimas Shidqi Parikesit、Yujin Huang 等
  - T2C 从分布式系统已有 test code 自动生成生产运行时 semantic checker：静态分析抽取测试设置、操作和 assertion，动态分析识别具体对象与状态，再把一次性 test generalize 成可持续检查真实请求/状态的监测逻辑。在四个大型系统中生成数十至数百个 checker，能检测复现的 20 个 silent failure 中 15 个且开销小。
  - 相较专家另写 production invariant/checker，核心创新是把维护较好的测试套件视为隐含语义规格，自动消除测试环境依赖并迁移到线上。
  - 生产分布式系统、Silent Failure、Test-to-Checker、静态-动态程序分析

- [Picsou: Enabling Replicated State Machines to Communicate Efficiently](https://www.usenix.org/conference/osdi25/presentation/frank)
  - UC Berkeley、University of Oregon、University of Michigan；Reginald Frank、Micah Murray、Chawinphat Tankuranand 等
  - Picsou 为两个 crash/BFT replicated state machine 之间提供 Cross-Cluster Consistent Broadcast，确保消息跨集群有序、可靠且不因副本重传爆炸。Quack（quorum acknowledgment）让发送集群精确判断目标集群已确定接收或很可能丢失，正常时 metadata 为常数、故障时只重发必要消息；灾备和 reconciliation 等场景最高比既有方案快 24 倍。
  - 相较把每个 RSM 当普通 endpoint、由所有副本成对确认，核心创新是把 quorum knowledge 压缩成跨集群 ACK 语义，像 TCP 一样只对真正缺失的数据恢复。
  - Replicated State Machine、跨集群一致广播、Quorum Acknowledgment、容错通信

- [FineMem: Breaking the Allocation Overhead vs. Memory Waste Dilemma in Fine-Grained Disaggregated Memory Management](https://www.usenix.org/conference/osdi25/presentation/wang-xiaoyang)
  - University of Science and Technology of China、Google；Xiaoyang Wang、Yongkun Li、Kan Wu 等
  - FineMem 为 RDMA disaggregated memory 提供 4 KB/2 MB 级远端分配而不退回 GB 级粗粒度。它预注册每个 compute node 的大 MR，用 memory window 和可信本地 allocation service 隔离细分区域；lock-free one-sided RDMA protocol 直接操作分配元数据，memory node CPU 不参与，并以日志在 compute failure 后恢复一致性。分配延迟最高降低 95%。
  - 相较每次细分都注册 MR、代价过高，或预留大块造成浪费，核心创新是把昂贵注册与实际分配解耦，再用 RDMA window 恢复细粒度保护边界。
  - Disaggregated Memory、细粒度远端分配、RDMA Memory Window、One-Sided Metadata

- [To PRI or Not To PRI, That's the question](https://www.usenix.org/conference/osdi25/presentation/wang-yun)
  - Shanghai Jiao Tong University、Alibaba Group；Yun Wang、Liang Chen、Jie Ji 等
  - VIO 让未广泛支持 PCIe PRI 的 NIC/存储设备也能在 VM memory oversubscription 下动态 passthrough。shadow available queue 根据 IOPS 压力在 virtio 路径与直通间切换；每次 DMA 在 virtio data plane 通过 IOPA snooping 确认页面已驻留、避免 device page fault，而 interrupt 仍直达 guest。已部署 30 万 VM，每日回收相当于 3 万 VM 的内存且不破坏 SLO。
  - 相较 SR-IOV 必须静态 pin 全部 guest memory、软件虚拟 I/O 又损失性能，核心创新是逐 I/O 验证 DMA 地址并按压力切换数据路径，以纯软件兼容现有硬件。
  - VM I/O 虚拟化、动态 Device Passthrough、Memory Oversubscription、IOPA Snoop

- [Enabling Efficient GPU Communication over Multiple NICs with FuseLink](https://www.usenix.org/conference/osdi25/presentation/ren)
  - HKUST、USTC、MetaX、MIT、Peking University、Meta；Zhenghang Ren、Yuxuan Li、Zilong Wang 等
  - FuseLink 解决多 NIC 训练节点中静态 GPU–NIC 绑定遇到 MoE All-to-All、推荐 embedding 或 LLM serving 非均匀流量时的热点。它把 NVLink/PCIe 等机内高速连接纳入跨机网络，让 GPU relay 流量到空闲 NIC，并透明集成 NCCL；两台服务器 GPU 间最高 212 GB/s，LLM 首 token、MoE 和推荐训练分别获得显著加速。
  - 相较每块 GPU 只能走固定 NIC，核心创新是把机内 GPU 互连当作跨 NIC load-balancing fabric，运行时为流量选择出口而无需改 ML 应用。
  - 多 NIC GPU 通信、NCCL、GPU Traffic Relay、MoE/LLM 网络负载均衡

- [Tigon: A Distributed Database for a CXL Pod](https://www.usenix.org/conference/osdi25/presentation/huang-yibo)
  - The University of Texas at Austin、UIUC；Yibo Huang、Haowei Chen、Newton Ni 等
  - Tigon 在 CXL pod 内让多台主机通过共享 CXL memory 上的 atomic operation 同步事务，而不通过网络消息交换。为应对 CXL 比 DRAM 慢且缺乏完整跨机 cache coherence，系统重新组织热点元数据、访问与同步路径，减少远端流量；TPC-C/YCSB 中相对把 CXL 仅作 transport 的 shared-nothing 数据库最高快 2.5 倍，相对 RDMA 数据库最高 18.5 倍。
  - 相较仅用 CXL 搬消息，核心创新是把共享内存 atomic 直接提升为跨主机 concurrency-control primitive，在有限 coherence 条件下重构数据库同步。
  - CXL Pod、分布式内存数据库、共享内存原子操作、事务并发控制

- [Mako: Speculative Distributed Transactions with Geo-Replication](https://www.usenix.org/conference/osdi25/presentation/shen-weihai)
  - Stony Brook University、Google、Microsoft Research、University of Pennsylvania；Weihai Shen、Yang Cui、Siddhartha Sen 等
  - Mako 是强一致、跨地域复制且可分片扩展的 transactional KV store。它将本地 transaction execution 与后台 geo-replication 解耦，允许 2PC 参与者在 commit/abort 决定尚未被远端持久复制前就投机推进后续 transaction，同时用协议限制 shard failure 时的 cascading abort 范围；Azure 上 10 shard 达 366 万 TPC-C txn/s。
  - 相较分布式事务必须等待共识/跨地域复制后才能继续，核心创新是 speculative 2PC 在保持 bounded abort 与容灾语义下隐藏复制 RTT。
  - Geo-Replicated Transaction、Speculative 2PC、执行-复制解耦、Transactional KV

- [Quake: Adaptive Indexing for Vector Search](https://www.usenix.org/conference/osdi25/presentation/mohoney)
  - University of Wisconsin–Madison、Apple、University of Waterloo；Jason Mohoney、Devesh Sarda、Mengze Tang 等
  - Quake 面向 RAG/推荐中数据和热点持续变化的向量检索。多层 partition index 根据更新与访问频率在线 split/merge，cost model 用分区大小和命中频率预测 latency；查询时 recall estimator 动态选择探查参数，NUMA-aware intra-query parallelism 吃满内存带宽。动态负载下查询延迟比 SVS、DiskANN、HNSW、SCANN 降 1.5–38 倍，更新延迟降 4.5–126 倍。
  - 相较索引拓扑和 search breadth 离线固定，核心创新是同时闭环调整数据分区与单查询执行参数，并以 latency/recall 模型分别约束两者。
  - RAG/向量检索基础设施、Adaptive ANN Index、Recall Estimation、NUMA 并行搜索

- [Achieving Low-Latency Graph-Based Vector Search via Aligning Best-First Search Algorithm with SSD](https://www.usenix.org/conference/osdi25/presentation/guo)
  - Tsinghua University；Hao Guo、Youyou Lu
  - PipeANN 将 billion-scale graph ANN 的 best-first search 改成适配 SSD 的 pipeline，不再严格等待本轮随机读取完成才决定下一轮计算/I/O，而是维护可并行展开的候选和 outstanding read，在不牺牲 recall 时隐藏设备延迟。其延迟仅为内存 Vamana 的 1.14–2.02 倍、为 on-disk DiskANN 的 35%。
  - 相较按算法逻辑逐步同步发 SSD read，核心创新是放松跨 search step 的 compute–I/O 次序，在保持 best-first 语义的同时形成足够 I/O 并行度。
  - 磁盘向量检索、Graph ANN、SSD I/O Pipeline、Best-First Search

- [Skybridge: Bounded Staleness for Distributed Caches](https://www.usenix.org/conference/osdi25/presentation/lyerly)
  - Meta Platforms、OpenAI；Robert Lyerly、Scott Pruett、Kevin Doherty 等
  - Skybridge 为 Meta 跨地域 cache 提供两秒 bounded staleness：不替换负责可靠最终交付的主 replication pipeline，而建立与其故障尽量不相关的轻量 out-of-band real-time update stream；主线丢失/延迟时旁路先传播新值。仅占 cache deployment 0.54% 规模，却让 99.99998% 写在两秒内可见。
  - 相较给完整复制链路继续堆冗余，核心创新是拆分“最终可靠”和“实时新鲜”两种职责，用极小、独立失败域的旁路提高高分位 freshness。
  - 分布式缓存、Bounded Staleness、Out-of-Band Replication、高可用数据传播

- [KPerfIR: Towards a Open and Compiler-centric Ecosystem for GPU Kernel Performance Tooling on Modern AI Workloads](https://www.usenix.org/conference/osdi25/presentation/guan)
  - UC San Diego、Meta、George Mason University、OpenAI；Yue Guan、Yuanwei Fang、Keren Zhou 等
  - KPerfIR 把 GPU kernel profiling 能力嵌入 Triton 编译流程，以多层 IR 和 compiler pass 编写可组合性能工具，能在源码、IR、指令/硬件事件之间映射，并观察细粒度 function unit overlap 等传统 profiler 难表达的问题。实测约 8.2% 开销、2% 相对误差，并产生可直接指导 kernel 优化的 intra-kernel 证据。
  - 相较每个 GPU/编译层级各有封闭 profiler，核心创新是把 instrumentation 与 measurement 表达成可移植 compiler transformation，建立性能工具的开放复用接口。
  - GPU Kernel Profiling、Compiler-Centric Tooling、Triton、Intra-Kernel 性能分析

- [Mirage: A Multi-Level Superoptimizer for Tensor Programs](https://www.usenix.org/conference/osdi25/presentation/wu-mengdi)
  - Carnegie Mellon University、Peking University、Penn State、Purdue University、Weizmann Institute；Mengdi Wu、Xinhao Cheng、Shengyu Liu 等
  - Mirage 用统一 µGraph 表示 GPU kernel、thread block、thread 三层 tensor program，一次搜索可同时做代数重写、schedule 变换和新 custom kernel 生成，而不被编译层级边界切开。抽象解释式 pruning 大幅删除不可能最优的空间并保留一定最优性保证，概率等价验证则检查候选与输入程序一致；在已高度优化 DNN 上仍超过既有编译器；评测包含 LLaMA、Falcon 和 Mixtral 等 LLM 的注意力、MoE 与 LoRA 算子。
  - 相较图优化、kernel fusion 和 thread schedule 分阶段贪心执行，核心创新是将三层决策放进同一 superoptimization IR，并把可证明剪枝与等价验证接入搜索。
  - Tensor Superoptimization、Multi-Level µGraph、抽象剪枝、概率等价验证

- [QiMeng-Xpiler: Transcompiling Tensor Programs for Deep Learning Systems with a Neural-Symbolic Approach](https://www.usenix.org/conference/osdi25/presentation/dong)
  - USTC、Cambricon、Institute of Computing Technology CAS、Institute of Software CAS；Shouyang Dong、Yuanbo Wen、Jun Bi 等
  - QiMeng-Xpiler 将 Intel VNNI、CUDA、AMD HIP、Cambricon BANG 间的低层 tensor program 自动移植。LLM 按 meta-prompt 逐 pass 生成大尺度结构变换，symbolic synthesis 只在局部搜索并修复不正确片段；hierarchical autotuning 再选择 pass 参数和顺序，平均 95% 正确完成跨四平台翻译。
  - 相较 LLM 单次翻译难保正确、纯符号搜索又空间爆炸，核心创新是让神经生成负责提出接近答案的程序、符号合成负责局部 correctness repair，并继续对变换序列调优。
  - LLM for Systems、Tensor Program Transcompilation、Neural-Symbolic Synthesis、跨加速器代码迁移

- [WaferLLM: Large Language Model Inference at Wafer Scale](https://www.usenix.org/conference/osdi25/presentation/he)
  - University of Edinburgh、Microsoft Research；Congjie He、Yeqi Huang、Pei Mu 等
  - WaferLLM 面向 Cerebras WSE2 类数十万核心、mesh 互连、分布式片上 SRAM 的 wafer-scale accelerator。PLMR model 描述 placement、local memory、mesh routing 和计算约束，据此设计 wafer-scale 模型并行以及 MeshGEMM/MeshGEMV，将权重/激活映射到二维核心阵列；完整 LLM 推理比 A100 集群上的 SGLang/vLLM 快 10–20 倍。
  - 相较沿用假设大共享 HBM 的 GPU tensor parallel，核心创新是围绕分布式片上内存和超密 mesh 从 cost model、并行到核心算子整体重做 LLM runtime。
  - LLM 推理加速、Wafer-Scale Accelerator、MeshGEMM/GEMV、片上分布式并行

<a id="blitzscale"></a>

- [BlitzScale: Fast and Live Large Model Autoscaling with O(1) Host Caching](https://www.usenix.org/conference/osdi25/presentation/zhang-dingyan)
  - Shanghai Jiao Tong University、Huawei Cloud；Dingyan Zhang、Haotian Wang、Yang Liu 等
  - BlitzScale 为 serverless model service 在多主机间快速扩 LLM 副本：权重不依赖每台主机完整 DRAM/NVMe cache，而通过空闲的 GPU compute network multicast，从已有 GPU 向新实例分发，因此 host cache 为零或 O(1)；扩容又从 instance 粒度细化到 layer，新节点只要装好某层即可接管过载实例对应计算。真实负载尾延迟比 ServerlessLLM 最多低 94%。
  - 相较等完整模型加载后才接流量，核心创新是同时打破“权重必须经主机存储”和“副本必须整机就绪”两项假设，以 layer-level live scaling 边传边分担计算。
  - LLM Serverless、Live Autoscaling、GPU Multicast Weight Loading、Layer-Level Offload

- [Bayesian Code Diffusion for Efficient Automatic Deep Learning Program Optimization](https://www.usenix.org/conference/osdi25/presentation/jeong)
  - Ulsan National Institute of Science and Technology；Isu Jeong、Seulki Lee
  - Bayesian code diffusion 把 tensor schedule 候选视为程序分布：从 prior 出发依据实测/成本模型形成 posterior，再迭代扩散高概率代码区域；预训练后微调的 cost model 跨算子和硬件快速适应。集成 Ansor 后，在 CPU/GPU 多种模型上达到同等执行 latency 所需的 autotuning 时间最高缩短 3.31 倍。
  - 相较对离散 schedule 随机/进化采样，核心创新是用贝叶斯先验—后验更新指导程序空间的逐轮扩散，并复用 cost-model knowledge 降低每个新任务冷启动。
  - 深度学习编译调优、Bayesian Program Search、Cost Model Transfer、Tensor Schedule

- [Training with Confidence: Catching Silent Errors in Deep Learning Training with Automated Proactive Checks](https://www.usenix.org/conference/osdi25/presentation/jiang)
  - University of Michigan；Yuxuan Jiang、Ziming Zhou、Boyu Xu 等
  - TrainCheck 从具体训练作业自动推断 tensor shape、数值演化、optimizer/update 关系等 invariant，并在每个 iteration 主动检查，在 loss 最终异常前给出违规状态和 debugging context。它在 20 个不同根因的真实 silent training error 中首轮即发现 18 个，还找到主流 training library 的 6 个未知 bug。
  - 相较等待 loss/accuracy 崩溃或依靠手写 assertion，核心创新是从训练执行自身学习作业专属不变量，并把检测点推进到错误传播前的单迭代内部。
  - 训练可靠性、Silent Error、自动不变量推断、主动运行时检查

- [Neutrino: Fine-grained GPU Kernel Profiling via Programmable Probing](https://www.usenix.org/conference/osdi25/presentation/huang-songlin)
  - The University of Hong Kong；Songlin Huang、Chenshu Wu
  - Neutrino 在 GPU assembly 层插入 programmable probe，可按 instruction 观察时间事件和运行值，不依赖某代硬件有限 counter，也不要求 kernel 独占 profiler。Densified Memory Access Timeline 将采到的稀疏访问重建成可视时间线；Linux 实现同时支持 NVIDIA/AMD，低开销揭示 kernel 内访存与执行细节。
  - 相较 vendor profiler 只能给 kernel-level aggregate 或固定事件，核心创新是将探针编程下沉到汇编指令层，以统一接口跨硬件采集 time/value 两个域。
  - GPU Kernel Profiling、Assembly Probing、Memory Access Timeline、跨 NVIDIA/AMD 工具

- [Principles and Methodologies for Serial Performance Optimization](https://www.usenix.org/conference/osdi25/presentation/park-sujin)
  - Georgia Institute of Technology；Sujin Park、Mingyu Guan、Xiang Cheng、Taesoo Kim
  - 该工作将串行关键路径优化归纳为 removal、replacement、reordering 三原则和 batching、caching、precomputing、deferring、relaxation、contextualization、hardware specialization、layering 八种方法，并验证它们能解释过去十年 OSDI/SOSP 优化。SysGPT 在整理后的论文分析上微调，为具体系统上下文生成符合框架、比 GPT-4 更具体可行的建议。
  - 相较优化依赖工程师零散直觉，核心创新是给出覆盖性方法 taxonomy，并将它编码进专用语言模型，形成可查询的性能优化知识接口；SysGPT 属于 LLM for Systems，不是自主执行验证的 Agent。
  - LLM for Systems、性能优化方法论、SysGPT、串行关键路径

- [Söze: One Network Telemetry Is All You Need for Per-flow Weighted Bandwidth Allocation at Scale](https://www.usenix.org/conference/osdi25/presentation/wang-weitao)
  - Rice University；Weitao Wang、T. S. Eugene Ng
  - Söze 在 commodity Ethernet 上做分布式 per-flow weighted bandwidth allocation，不要求控制器掌握每条 flow、拓扑或 route。端点只利用交换机提供的简单 telemetry 反馈，结合 flow weight 计算发送速率并收敛到加权份额，在路径变化和大规模 flow 下仍精确；TPC-H job completion time 显著改善。
  - 相较集中式控制器收集全网状态或交换机维护 per-flow queue，核心创新是证明一个通用 telemetry signal 足以让端点局部闭环实现全局 weighted allocation。
  - 数据中心带宽分配、Network Telemetry、去中心化速率控制、Weighted Fairness

- [Decouple and Decompose: Scaling Resource Allocation with DeDe](https://www.usenix.org/conference/osdi25/presentation/xu)
  - Harvard University、UIUC；Zhiying Xu、Minlan Yu、Francis Y. Yan
  - DeDe 抽象出 cluster scheduling、traffic engineering、load balancing 等大规模问题的共同 separable 结构：总效用由单个 resource-demand allocation 相加，约束分别属于资源端或需求端。算法先解耦纠缠约束，再交替并行求解 per-resource 与 per-demand 子问题；Python 建模接口可替代商用 solver，在三个任务上更快且给出更高质量分配。
  - 相较为单一领域手写 heuristic，核心创新是利用跨领域共有的双侧可分结构，建立既有理论依据又可复用的分解优化框架。
  - 云资源分配、Decouple-and-Decompose、并行优化、调度/流量工程统一建模
