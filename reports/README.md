# Research Reports

Research surveys, landscape reports, and research-direction analyses. Each
report has its own directory, with the report body in `REPORT.md` and supporting
evidence beside it. Name directories `YYMMDD-topic[-coverage-years]`, using
a stable six-digit date prefix for chronological sorting. Use the documented
report date, or the creation date when no report date is recorded; later edits
do not change the prefix.
