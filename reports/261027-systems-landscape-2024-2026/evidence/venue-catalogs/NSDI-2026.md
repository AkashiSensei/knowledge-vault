# NSDI 2026 论文列表

NSDI 2026 正式技术议程共收录 150 篇论文。以下标题链接至 USENIX 官方页面；每篇依次列出作者与机构、研究场景和系统机制、相较既有方法的核心创新，以及细粒度方向。150 份官方 PDF 均已保存至 `reference/NSDI/2026/`。

- [UNUM: A New Framework for Network Control](https://www.usenix.org/conference/nsdi26/presentation/chen-jiayi)
  - Jiayi Chen, UT Austin; Nihal Sharma, Capital One; Debajit Chakraborty, Saurabh Agarwal, Jeffrey Zhou, Aditya Akella, and Sanjay Shakkottai, UT Austin
  - UNUM 不直接替换 congestion-control/ABR controller，而用统一 Transformer state embedder 增强其观测：模型读取多个 RTT 尺度的历史 RTT、throughput、loss 等统计，从多种网络场景预训练出包含 workload/path latent factor 的当前状态表示，并预测未来状态；原控制器把 embedding 作为额外输入后在非平稳网络中更准确决策。
  - 相较用瞬时值/滑动平均手工近似网络状态、或每个任务单独训练端到端 policy，核心创新是跨 CC 与视频任务复用的历史感知 state representation，把状态估计与 action policy 解耦。
  - Learning-based Networking、Network State Embedding、Transformer、Congestion Control、Adaptive Bitrate

- [BURST: Seeking High-performance, Interoperability and Scalability in Soft-RDMA](https://www.usenix.org/conference/nsdi26/presentation/shen)
  - Huijun Shen, Hunan University; Zelong Yue, Jian Yang, Zhuo Jiang, Lang An, Yulin Chen, Yong Zhang, Luochangqi Ding, Xiaolong Zhong, Zhihong Wang, Jie Ding, Hongyu Wu, and Jianxi Ye, ByteDance Inc.; Xijin Yin, Xingyu Zhang, Xingyu Guo, and Guo Chen, Hunan University
  - BURST 是运行在普通 Ethernet NIC 上、却与标准 RDMA Verbs application 互通的 userspace Soft-RDMA stack。独立进程用 lock-free DPDK data plane 做 RoCE packet/reliability，Intel DSA 分担 data movement，kernel-bypass connection manager 加速建连；非 RNIC server 因而可直接与商业 RNIC 通信，400G 达 98.7% line rate。
  - 相较 Linux RXE 的内核软 RDMA CPU 开销过高、TCP fallback 又破坏 RDMA 语义，核心创新是以独立 userspace service 完整实现可互操作 Verbs/RoCE，并组合 DPDK+DSA 消除 400G 瓶颈。
  - Soft-RDMA、RDMA Interoperability、DPDK、Intel DSA、Heterogeneous Datacenter

- [PolicyCache: Intra-flow Learning in Congestion Control](https://www.usenix.org/conference/nsdi26/presentation/tian)
  - Han Tian, Han Wang, and Wenbo Li, University of Science and Technology of China; Xudong Liao, Decang Sun, and Wenxue Li, Hong Kong University of Science and Technology; Donghui Chen, Bin Huang, and Senbo Fu, Huawei Technologies Co., Ltd.; Junxue Zhang, University of Science and Technology of China; Dian Shen, Southeast University; Kai Chen, Hong Kong University of Science and Technology
  - PolicyCache 让每条 TCP flow 在自己的生命周期内完成探索、训练和执行，不依赖过去 flow 或跨环境泛化。它以轻量 non-parametric tree 缓存 network state 到 rate/action 的局部经验，在线探索新状态，并随证据在多个模型间动态切换，因此单 flow 内就能快速适应 RTT/bandwidth 变化且保持公平。
  - 相较离线学习 CC 容易遇到 distribution shift、跨 flow online learning 收敛太慢，核心创新是 intra-flow learning 范式：把短期经验组织成可即时复用的 policy cache。
  - Congestion Control、Intra-flow Learning、Online Exploration、Non-parametric Model、Network Adaptation

- [FastServe: Iteration-Level Preemptive Scheduling for Large Language Model Inference](https://www.usenix.org/conference/nsdi26/presentation/wu-bingyang)
  - Bingyang Wu, Yinmin Zhong, Zili Zhang, Shengyu Liu, Fangyue Liu, Yuanhang Sun, Gang Huang, Xuanzhe Liu, and Xin Jin, School of Computer Science, Peking University
  - FastServe 为 autoregressive LLM inference 在每个 output-token iteration 边界抢占 request。skip-join MLFQ 用已知 input length 选择新 request 的初始队列并跳过更高层，随后按已服务时间降级；抢占时 GPU memory manager 主动把 KV/intermediate state 在 GPU 与 host 间换入换出，从而缓解长生成阻塞短请求。
  - 相较 vLLM 等把整个生成请求 run-to-completion，核心创新是利用 token iteration 的天然安全点实现低成本 preemption，并为仅知 input、未知 output length 的半信息场景改造 MLFQ。
  - LLM Inference Serving、Token-level Preemption、MLFQ、KV Cache Swapping、Head-of-line Blocking

- [SYMI: Efficient Mixture-of-Experts Training via Model and Optimizer State Decoupling](https://www.usenix.org/conference/nsdi26/presentation/skiadopoulos)
  - Athinagoras Skiadopoulos, Stanford University; Mark Zhao, University of Colorado Boulder; Swapnil Gandhi, Stanford University and NVIDIA; Thomas Norrie, OpenAI; Shrijeet Mukherjee, NVIDIA; Christos Kozyrakis, Stanford University and NVIDIA
  - SYMI 在 MoE training 的每个 iteration 按 token-to-expert load 重新配置 expert GPU 数，但只动态移动较小的 model parameter；每个 expert 体积更大的 optimizer state 始终静态分片在所有 training node，参数更新时顺带把新 weight 发到下一轮 placement，避免额外 migration，也无需丢弃热门 expert 的 token。
  - 相较静态放置造成 expert imbalance、动态迁移完整 parameter+optimizer state 又昂贵，核心创新是解耦两类状态的 placement/lifetime，复用 weight update 承担 per-iteration 迁移。
  - MoE Training、Expert Placement、Optimizer-state Decoupling、Load Balancing、Time-to-convergence

- [Towards Performance Robustness for Microservices](https://www.usenix.org/conference/nsdi26/presentation/saxena)
  - Divyanshu Saxena and Gaurav Vipat, UT Austin; Jiaxin Lin, Cornell University; Jingbo Wang, Purdue University; Isil Dillig, Sanjay Shakkottai, and Aditya Akella, UT Austin
  - Galileo 为 microservice autoscaler/admission controller 增加运行时 Performance Robustness Certificate。队列模型根据 request type、service graph、负载 burst、contention 与 shared dependency 等扰动，快速给出候选 action 下 tail latency 的统计上界；两个已有 learned controller 据证书过滤/修正脆弱动作，在环境变化时仍满足 SLO。
  - 相较 learned controller 只优化训练分布平均回报，核心创新是把“该动作对一组环境扰动仍安全”表示为可在线计算的证书，并作为 controller-agnostic guardrail。
  - Microservice Control、Performance Robustness、Queueing Model、Learned Controller、SLO Guardrail

- [Pilot Execution: Simulating Failure Recovery In Situ for Production Distributed Systems](https://www.usenix.org/conference/nsdi26/presentation/li-zhenyu)
  - Zhenyu Li, University of Virginia; Angting Cai, University of California San Diego; Chang Lou, University of Virginia
  - PILOT 在生产 distributed system 真正执行 failover、re-replication、restart 等 recovery action 前做 in-situ dry run。runtime library 隔离并模拟动作对跨组件 state/dependency 的影响，operator 先观察将产生的级联变化再决定是否提交；在五个系统中重现 20 个已知 recovery failure 的 17 个并发现 HBase 新 bug。
  - 相较 staging 环境缺少真实拓扑/状态、生产 chaos test 又会造成不可逆影响，核心创新是新的 pilot-execution 语义：在原系统状态上推演 recovery side effect 而不生效。
  - Distributed-system Recovery、In-situ Simulation、Dry Run、Failure Safety、Cross-component Interaction

- [BLADE: Adaptive Wi-Fi Contention Control for Next-Generation Real-Time Communication](https://www.usenix.org/conference/nsdi26/presentation/guo-fengqian)
  - Fengqian Guo, Tencent; Yuhan Zhou, Peking University and Tencent; Longwei Jiang and Congcong Miao, Tencent; Yuxin Liu, University at Buffalo, SUNY; Chenren Xu, Peking University; Hancheng Lu, Institute of Artificial Intelligence, China; Chang Wen Chen, The Hong Kong Polytechnic University; Yaxiong Xie, University at Buffalo, SUNY; Honghao Liu, Tencent
  - BLADE 面向 cloud gaming/XR 的 Wi-Fi last mile，让每个 AP/station 根据本地观测的 channel contention 分布式调整 contention window。控制器针对短时 packet-delivery drought 而非平均吞吐，所有 transmitter 快速公平收敛；商业 AP 实验在重载下把 packet tail latency 降 5 倍以上、游戏 stall 降 90% 以上。
  - 相较标准 802.11 用固定退避规则、端到端 CC 无法控制无线争用，核心创新是在不依赖集中 coordinator 的情况下让全体发送端以实时 contention level 自适应 CW。
  - Wi-Fi、Contention Control、Real-time Communication、Tail Latency、Distributed Adaptation

- [Observability Is Eating Your Cores: Fine-Grained Analysis of Microservice Metrics with IPU-Hosted Sketches](https://www.usenix.org/conference/nsdi26/presentation/cornacchia)
  - Alessandro Cornacchia, King Abdullah University of Science and Technology; Theophilus A. Benson, Carnegie Mellon University; Muhammad Bilal and Marco Canini, King Abdullah University of Science and Technology
  - μView 把 microservice metric 的细粒度 streaming analysis 从 host CPU 放到邻近 IPU。IPU data plane 持续用 sketch 聚合高频 event，只在接近 SLO violation 时保留/上报有信息量的细节并发出 proactive signal，既避免全量 telemetry 的 core/storage 成本，也不靠粗采样漏掉短异常。
  - 相较 host agent 全量收集或低频 sampling，核心创新是用 IPU proximity + online sketch 在数据产生处实时筛选，并把“预警所需信息”而非原始指标作为输出。
  - Microservice Observability、IPU、Streaming Sketch、SLO Prediction、Telemetry Offload

- [MirrorNet: High-fidelity and Scalable Network Emulation for Software-defined WAN](https://www.usenix.org/conference/nsdi26/presentation/miao)
  - Congcong Miao, Tencent; Yuejie Wang, Peking University; Jianming Wang, Xuefeng Ji, Guozhi Shan, Sirui Li, Pan Fang, and Yanke Zhang, Tencent; Jialin Li, National University of Singapore; Xianneng Zou, Tencent; Guyue Liu, Peking University Operational Systems Paper
  - MirrorNet 是软件定义 WAN 的生产 digital twin：增量存储并按秒回放 controller state、data-plane topology/config 和 traffic，update protocol 持续保持 twin 与生产网一致；custom orchestrator 可快速拉起多个大规模副本并行做 troubleshooting、参数调优、变更测试和 capacity assessment。
  - 相较只模拟拓扑/流量或抽取部分控制状态，核心创新是统一重建 controller—data plane—traffic 的历史全状态，并以增量机制兼顾秒级忠实度和多副本规模。
  - WAN Digital Twin、Network Emulation、State Replay、Change Testing、Production Operations

- [From Bits to Tokens: Knowledge-Driven Generative Communication of Multimodal Data](https://www.usenix.org/conference/nsdi26/presentation/chen-xingyu)
  - Xingyu Chen, University of California San Diego; Zihao Feng, University of Southern California; Wuqiong Zhao, University of California San Diego; Jianrong Ding, Chinese University of Hong Kong; Ke Sun, University of Michigan Ann Arbor; Xinyu Zhang, University of California San Diego
  - KDC 在无线传输图像、视频等 multimodal sensor data 时不追求 bit-perfect reconstruction。task-aware transmitter 用 foundation model 把原始内容变成 semantic token/embedding，并按下游感知/决策重要性选择发送；receiver 结合预训练 knowledge base 与逐步更新的 context 重构 task-relevant information，丢包时优雅降级且可 zero-shot 适配任务。
  - 相较传统 codec 保护所有 bit、端到端 learned codec 又需每任务重训，核心创新是让共享 foundation knowledge 成为通信双方的先验，只传任务新增的语义信息。
  - Semantic Communication、Multimodal Foundation Model、Wireless Network、Task-aware Coding、Generative Reconstruction

- [KeepON: Supporting Deterministic Traffic on Standard NICs](https://www.usenix.org/conference/nsdi26/presentation/xue-chuanyu)
  - Chuanyu Xue, University of Connecticut; Tianyu Zhang, University of Iowa; Andrew Loveless, NASA Johnson Space Center; Song Han, University of Connecticut
  - KeepON 让 commodity NIC 也能按 TSN 时隙确定性发包：driver 持续发固定大小 placeholder 建立不受 host scheduling/DMA 抖动影响的发送节拍，critical packet 到来后在预定 slot 原位替换 placeholder；未替换的占位包在 first-hop switch 丢弃，不污染后续网络。
  - 相较必须购买 TSN NIC 或靠软件定时直接 enqueue，核心创新是用持续占位把不可预测的普通 NIC queue 预热成确定性传输模板，再做 slot substitution。
  - Deterministic Networking、Commodity NIC、TSN、Placeholder Packet、Driver Scheduling

- [RASC: Enhancing Observability & Programmability in Smart Spaces](https://www.usenix.org/conference/nsdi26/presentation/karanika)
  - Anna Karanika, Kai-Siang Wang, Han-Ting Liang, Shalni Sundram, and Indranil Gupta, University of Illinois Urbana-Champaign
  - RASC 为智能家居/仓库 IoT action 在传统 request/response 外增加 Acknowledge、Start、Complete 三个可观测阶段。Home Assistant 可据此预测不同设备动作完成时间、快速区别未开始/执行中/失败、表达跨设备细粒度依赖，并按长达分钟的 action duration 调度 automation，SLO 表现提高 10–55%。
  - 相较 RPC 只知道请求已返回、无法观测物理动作进度，核心创新是把设备 action lifecycle 变成统一协议抽象，让监控与 scheduler 获得可组合的因果事件。
  - IoT、Smart Space、Action Lifecycle、Observability、Automation Scheduling

- [Decoding RSSI Compression in RFID: Dynamic RCS Modeling and Tag-Intrinsic Power Metrics for Reliable Backscatter Networks](https://www.usenix.org/conference/nsdi26/presentation/liu-jia)
  - Jia Liu, Yifei Ma, Xingyu Chen, and Haipeng Dai, Nanjing University; He Huang, Soochow University; Zihao Lin and Wei Zheng, Nanjing University; Junzhao Du, Xidian University; Guihai Chen, Nanjing University
  - 该工作发现 RFID reader 的 RSSI 会随入射功率发生 compression，导致上层把 tag/channel 质量估错。它以 dynamic radar cross section 建模根因，提出 channel-specific Interrogation Threshold Power 估链路、tag-intrinsic Backscatter Power Index 标识设备，并用一次现场 query 同时估计，开销降 99.8%、信道误差降 64.7%。
  - 相较把 raw RSSI 当线性、环境无关指标，核心创新是把 tag 的动态散射物理机制分解为链路阈值和设备固有指标，给 MAC/定位/感知提供可靠输入。
  - RFID、Backscatter Network、RSSI Compression、Radar Cross Section、Cross-layer Measurement

- [BBC: Enabling BLE to Support Bluetooth Classic](https://www.usenix.org/conference/nsdi26/presentation/cho)
  - Hsun-Wei Cho and Kang G. Shin, University of Michigan
  - BBC 让 BLE-only chip 与 Bluetooth Classic headphone 通信：它只借 BLE radio 发送/接收 raw FSK bit，Classic 的 baseband framing、link control、frequency hopping 等操作在 driver software 模拟，从而无需 dual-mode hardware 也能以 557 kbps 直接传音频。
  - 相较增加独立 Classic radio/双模芯片，核心创新是识别两种协议可复用的最小 PHY 能力，把所有不兼容部分上移到可部署的软件 emulation。
  - Bluetooth、BLE、Protocol Emulation、FSK PHY、Wireless Compatibility

- [SPLIDT: Partitioned Decision Trees for Scalable Stateful Inference at Line Rate](https://www.usenix.org/conference/nsdi26/presentation/parvez)
  - Murayyiam Parvez, Purdue University; Annus Zulfiqar, University of Michigan; Roman Beltiukov, UCSB; Shir Landau Feibish, University of Haifa; Walter Willinger, Northwestern University; Arpit Gupta, UCSB; Muhammad Shahbaz, University of Michigan
  - SPLIDT 在 programmable switch 上执行需跨多个 packet 统计 feature 的 decision tree。它把 tree 的 subtree 分区，每区只计算自己的 feature；packet recirculation 携带 in-band control state，让不同时段的分区复用同一 register/match key。配套 DSE 联合搜索 feature allocation、partition 与 depth，支持多 5 倍 stateful feature、仍扩到百万 flow。
  - 相较所有 feature 先算完再走一棵树而受硬件 state/action 限制，核心创新是把一次 inference 分摊到 packet sliding window，并在时间上复用 data-plane resource。
  - In-network ML、Decision Tree、Stateful Inference、Programmable Switch、Model Partitioning

- [Morphe: High-Fidelity Generative Video Streaming with Vision Foundation Model](https://www.usenix.org/conference/nsdi26/presentation/gong)
  - Tianyi Gong, Zijian Cao, and Zixing Zhang, The Chinese University of Hong Kong, Shenzhen, and Shenzhen Future Network of Intelligence Institute; Jiangkai Wu and Xinggong Zhang, Peking University; Shuguang Cui and Fangxin Wang, The Chinese University of Hong Kong, Shenzhen, and Shenzhen Future Network of Intelligence Institute
  - Morphe 用 vision foundation model 做端到端 generative video streaming：联合训练 visual tokenizer 与可变分辨率时空表示，在模拟带宽/loss 约束下决定发哪些 token；运行时按网络状态智能丢弃低价值 packet，receiver 由 VFM 补全时空内容，在实时延迟下以 H.265 少 62.5% 带宽保持相近画质。
  - 相较 pixel codec 已接近压缩极限、早期生成式视频延迟高且失真，核心创新是把 VFM semantic representation、network-aware tokenization 和 loss-resilient packet selection 一体训练。
  - Generative Video Streaming、Vision Foundation Model、Semantic Token、Loss Resilience、Adaptive Transmission

- [DroidSpeak: KV Cache Sharing Across Fine-tuned Model Variants](https://www.usenix.org/conference/nsdi26/presentation/liu-yuhan)
  - Yuhan Liu, Yuyang Huang, Jiayi Yao, Shaoting Feng, Zhuohan Gu, Kuntai Du, Hanchen Li, Yihua Cheng, and Junchen Jiang, University of Chicago; Shan Lu, Madan Musuvathi, and Esha Choukse, Microsoft
  - DroidSpeak 支持同架构但不同 fine-tuned weight 的多个 LLM 共享 prefix KV cache，适合 agent/compound-AI 中多个角色反复处理同一上下文。系统按实测质量敏感性只重算少数 layer 的 KV，其余直接从另一模型节点加载，并把 layer-wise recomputation 与 cache transfer pipeline overlap，prefill 快约 3.1 倍。
  - 相较 prefix cache 只能在同一模型复用，核心创新是刻画 fine-tuning 后各层 KV 的可迁移性并选择性修复，使跨模型 cache reuse 在质量可控时成立。
  - Agent Infra、Compound AI、Cross-model KV Cache、Fine-tuned LLM、Distributed Inference

- [Checkmate: Zero Performance Overhead Model Checkpointing via Network Gradient Replication](https://www.usenix.org/conference/nsdi26/presentation/bhardwaj)
  - Ankit Bhardwaj, Tufts University; Weiyang Wang, Jeremy Carin, Adam Belay, and Manya Ghobadi, Massachusetts Institute of Technology
  - Checkmate 为 data-parallel DNN 每个 iteration 建 checkpoint，但训练 GPU 不复制/暂停 model state。网络在做 gradient collective 时额外 multicast 一份 gradient 给 CPU shadow cluster，shadow 持有旧模型并按同样 optimizer update 演进出最新 checkpoint；故障后可恢复到上一轮，训练吞吐接近无 checkpoint。
  - 相较周期性把数百 GB parameter/optimizer state 从 GPU 导出，核心创新是利用网络中本就出现的 gradient 作为状态增量，在旁路副本异步重建 checkpoint。
  - Distributed Training、Checkpointing、Gradient Replication、Shadow Cluster、Failure Recovery

- [HybridMesh: A Hardware-software Hybrid Approach for Accelerating Service Mesh Ingress](https://www.usenix.org/conference/nsdi26/presentation/you)
  - Myoungsung You, University of Seoul; Jaehyun Nam, Dankook University; Minjae Seo, ETRI; Taejune Park, Chonnam National University; Seungwon Shin, KAIST
  - HybridMesh 加速 service-mesh ingress gateway：SmartNIC 处理适合硬件的 packet parsing、流量识别与 fast routing，CPU 上轻量 proxy 只保留复杂 L7 policy/traffic-management feature；两者按功能边界协同，避免全软件重复穿越内核，也不强把动态功能塞入受限硬件，HTTP throughput 提高 4.4 倍。
  - 相较纯 sidecar/Envoy 的 CPU path 或功能受限的全 SmartNIC offload，核心创新是按可变性与执行成本切分 ingress control/data function 的 hybrid architecture。
  - Service Mesh、Ingress Gateway、SmartNIC Offload、Microservices、Hardware-Software Co-design

- [Di-PS: System-Algorithm Co-Design for Asynchronous and Heterogeneous Cross-cluster LLM Training at Scale](https://www.usenix.org/conference/nsdi26/presentation/li-shengwei)
  - Shengwei Li, National Key Laboratory of Parallel and Distributed Computing; Qiaoling Chen, Shanghai Artificial Intelligence Laboratory and Nanyang Technology University; Zhiquan Lai, National Key Laboratory of Parallel and Distributed Computing; Penglong Jiao, Wenwen Qu, Kun Cai, Jiaxing Li, Peng Sun, and Xingcheng Zhang, Shanghai Artificial Intelligence Laboratory; Xiaoge Deng, Dongsheng Li, and Kai Lu, National Key Laboratory of Parallel and Distributed Computing; Tianwei Zhang, Nanyang Technological University Operational Systems Paper
  - Di-PS 跨最多 9 个异构、广域连接的 NPU cluster 异步训练 100B LLM。parameter-server path 高效交换大模型参数，two-stage optimizer 允许各 cluster 不等最慢者更新，并用 pseudo-gradient penalty 抑制 stale update 导致的发散；成员/资源变化时继续训练，万卡生产规模相对单集群仅 6% 开销。
  - 相较同步 cross-cluster all-reduce 被慢链路/异构算力锁步，核心创新是系统 parameter exchange、异步优化稳定项和 failure/resource elasticity 的联合设计。
  - Cross-cluster LLM Training、Asynchronous Parameter Server、Heterogeneous NPU、Stale Gradient、Fault Resilience

- [Stimpack: An Adaptive Rendering Optimization System for Scalable Cloud Gaming](https://www.usenix.org/conference/nsdi26/presentation/heo)
  - Jin Heo, Dolby Laboratories; Vic Wang, Ketan Bhardwaj, and Ada Gavrilovska, Georgia Institute of Technology
  - Stimpack 在 cloud-gaming edge 为每个用户动态选择 server-side rendering quality。它把 GPU/CPU 渲染成本与经当前网络有损压缩后真正到达用户的感知质量关联：若高质量 frame 会被压缩抹掉细节，就降低渲染开销并把资源给其他 session；multi-user allocator 以单位资源质量收益最大化整体 utility。
  - 相较始终最高画质渲染、再由 encoder 独立降码率，核心创新是跨 rendering 与 network compression 计算 marginal utility，避免生成注定无法传达的像素。
  - Cloud Gaming、Adaptive Rendering、Perceptual Quality、Edge Resource Allocation、Cross-layer Optimization
