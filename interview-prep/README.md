# 面试准备

按技术方向记录面试问题，以中文为主，回答保持简短，方便面试前回顾和口述。

- [[interview-prep/training|训练与显存]]：训练流程、显存组成、反向传播，以及激活与梯度的生命周期。
- [[interview-prep/transformer|Transformer 结构]]：Block 组件及现代模型的归一化、门控 FFN、KV 组织、位置编码、MoE 与多模态方向。
- [[interview-prep/multimodal|多模态模型]]：视觉编码器、连接器、语言模型、融合方式与理解/生成结构的区别。

每个方向使用一个文档，每个问题使用一个三级标题；同一方向内可以用二级标题分组。后续随实际讨论补充其他方向，不把尚未讲解的题目列成空条目。较长的概念解释链接到 `knowledge/`，这里保留简要回答和必要的条件。
