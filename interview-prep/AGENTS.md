# 面试准备目录约定

本目录遵循仓库根目录的 AGENTS.md；以下约定只适用于本目录。

- 主要使用中文，保留常见英文技术术语。
- 一个技术方向一个 Markdown 文档；README.md 维护方向索引。
- 每个问题使用一个三级标题（`###`），标题写成具体问句；二级标题用于分组。
- 回答通常为一小段，适合约一分钟内口述；必要时补一个简短例子、公式或表格。
- 记录实际讨论过的问题及有价值的追问，保留误解澄清；不自动填充尚未讲解的问题或空答案。
- 区分通用原理、实现相关行为和项目实际配置；不把知识理解写成已具备的实战经历。
- 详细概念优先链接到 knowledge/ 的具体标题；技术依据优先使用原始论文或官方文档。
- 新增或调整方向时更新 README.md，并检查内部链接与标题。
